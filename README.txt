GITHUB PAGES SETUP

The index.html in this package has already been added to the DevJel/email repository. It points to https://devjel.github.io/email/images/.

1. Extract this ZIP on your computer.
2. Open https://github.com/DevJel/email, choose Add file > Upload files, and drag the extracted images folder into the upload area. Commit the files to main.
3. Open the repository Settings > Pages. Under Build and deployment, choose Deploy from a branch, then select main and / (root), and save.
4. Wait for the Pages deployment to finish, then test https://devjel.github.io/email/ and the images in an email client.

Until the images are uploaded and Pages is enabled, the image links in index.html will not work.
