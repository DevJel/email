JELVAN EMAIL — GITHUB PAGES

index.html contains the employment inquiry email. The image files are stored in the repository root, alongside index.html; its image links point to those root files on GitHub Pages.

To publish: in repository Settings > Pages, under Build and deployment, choose Deploy from a branch, then select main and / (root), and save. Once the deployment finishes, open https://devjel.github.io/email/ and check the images and email layout.

The WebP cover is provided with a JPEG fallback for email clients. Test the HTML in your email platform before sending. If the images are moved to a folder later, update their URLs in index.html to match.
